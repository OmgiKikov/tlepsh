# Агент поддержки «Волна» (Python)

Программа-агент — `agent.py`. Она говорит с AHDE по протоколу v2 и трогать её
обычно не нужно.

**Правила поведения живут в `prompts/system.md`.** Это единственная editable
surface: она объявлена в `manifest.yaml` как `harness.files`, и именно её
правит цикл улучшения. Меняя поведение агента, меняйте этот файл.

Инструменты — `tools/*.tool.yaml` (описание для модели) и `bin/*` (исполняемый
файл). Их запускает хост в песочнице, а не сам агент.

Справочные документы — `data/kb/*.md`. Хост предоставляет `kb_search`: агент
получает найденные фрагменты и ссылается на них, не читая весь корпус заранее.
