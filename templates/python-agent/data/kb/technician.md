# Выезд мастера

Мастер нужен, когда проблема не решается перезагрузкой роутера: обрыв кабеля,
нет линка на порту, повреждение оборудования в подъезде.

Заявка создаётся в чате. Мастер приезжает в течение двух рабочих дней,
интервал согласовывается накануне по телефону.

Выезд бесплатный, если причина на стороне провайдера. Если повреждено
оборудование абонента — 800 ₽ за визит.
