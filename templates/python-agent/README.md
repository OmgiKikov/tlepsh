# Агент поддержки провайдера — на Python

Шаблон для случая, когда агент у вас уже есть и написан не на Pi, а обычной
программой. AHDE запускает `agent.py` как дочерний процесс и разговаривает с
ним по протоколу v1 — по одной строке JSON в каждую сторону.

## Что здесь лежит

| Файл | Зачем |
|---|---|
| `agent.py` | Сам агент. Стандартная библиотека, никаких зависимостей. |
| `prompts/system.md` | **Правила поведения. Это и есть editable surface.** |
| `tools/*.tool.yaml`, `bin/*` | Инструменты. Запускает их хост, в песочнице. |
| `data/kb/*.md` | Справочные документы, объявленные в `manifest.data`. |
| `evals/development.jsonl` | 8 стартовых кейсов: справка, поиск по абоненту, заявка, два диалога. |
| `http_bridge.py` | Если агент уже живёт за HTTP (Langflow, n8n, свой сервис). |

## С чего начать

```sh
ahde            # первый диалог спросит модель агента, судьи и симулятора
```

Заглушки `replace-with-model-id` в `manifest.yaml` править руками не нужно:
AHDE запишет выбранные модели отдельным ревьюируемым коммитом. Ключи он берёт
из переменных окружения по имени (`AHDE_MODEL_API_KEY` и соседние) — сами
значения не попадают ни в манифест, ни в улики.

## Что правит цикл улучшения

`manifest.yaml` объявляет `harness.files: [prompts/**]`. Это значит, что
предложения Билдера могут менять только системный промпт: программа-агент
остаётся вашей. Если поведение агента задаётся не промптом, а конфигом —
поменяйте этот список, и цикл будет править то, что вы назвали.

## Мир кейса

Кейс может описать состояние, в котором он происходит:

```json
{"id": "...", "input": "Договор 4412, какой тариф?",
 "world": {"state": {"accounts": {"4412": {"tariff": "Скоростной", "monthly": 800}}}}}
```

Хост кладёт путь к этому состоянию в `AHDE_WORLD`; `bin/get_account` читает
его, `bin/create_ticket` дописывает в него заявку. Один и тот же вопрос в
разных мирах — два разных кейса, и хеш датасета это различает.

## Свой агент вместо этого

Оставьте `manifest.yaml`, `evals/` и `tools/`, замените `agent.py` своим и
поменяйте `execution.command.argv`. Требования к программе ровно три:

1. Читать строки JSON из stdin, писать строки JSON в stdout, каждая с `"v": 1`.
2. Отвечать на `user` сообщением `assistant` — оно заканчивает ход.
3. Ничего постороннего в stdout. Диагностика — в stderr.

Всё остальное — инструменты, расход токенов, мир — необязательно.
