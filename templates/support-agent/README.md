# templates/support-agent

Scaffold a Russian-language first-line support agent with `ahde init <dir> --template templates/support-agent`, then run `ahde` in that directory and stay in the conversation: the first screen asks which model the agent should use and writes `manifest.yaml` for you through a reviewed commit, and the judge — needed only once a case uses a `judge` grader — is asked the same way. Everything still marked `REPLACE-ME` is the Builder's starting material, and describing the agent is how it gets replaced: `spec.md` so every "Success criteria" bullet maps 1:1 onto a grader, `AGENTS.md` — its two load-bearing sections are "call the tool before answering" and a literal first line that names the request type, the pattern that carried a 9B model from a 41.7% to a 98.3% pass rate in `docs/DEMO_REAL_MODEL.md` — the `check_account` stub in `bin/` and `tools/` in place of the real system, and 30–50 real cases in `evals/development.jsonl`. `ahde validate --target .` is the local readiness check and names every file that still carries a stand-in; `ahde` itself approves the Spec, runs the baseline, proposes the change and holds the ship gate.
