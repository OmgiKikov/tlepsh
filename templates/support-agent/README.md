# templates/support-agent

Scaffold a Russian-language first-line support agent with `ahde init <dir> --template templates/support-agent`, then work through the `REPLACE-ME` markers: name the model and its `apiKeyEnv` in `manifest.yaml` (a judge block too, but only if a case uses a `judge` grader), write `spec.md` so every "Success criteria" bullet maps 1:1 onto a grader, fill `AGENTS.md` — its two load-bearing sections are "call the tool before answering" and a literal first line that names the request type, the pattern that carried a 9B model from a 41.7% to a 98.3% pass rate in `docs/DEMO_REAL_MODEL.md` — replace the `check_account` stub in `bin/` and `tools/` with the real system, and put 30–50 real cases in `evals/development.jsonl`; then `ahde validate --target .`, `ahde spec approve --target .`, and baseline with `ahde run --target . --label baseline --repetitions 2`.
